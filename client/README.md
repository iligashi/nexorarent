# Nexora web application

The Next.js customer and admin application is part of the Nexora Rent a Car monorepo. For project architecture, local setup, environment variables, screenshots, test commands, and production guidance, see the [repository README](../README.md).

## Client commands

Run these commands from `client/`:

| Command | Purpose |
|---|---|
| `npm run dev` | Start the Next.js development server |
| `npm run lint` | Run ESLint |
| `npm run build` | Create a production build |
| `npm start` | Serve the production build |
| `npm run test:e2e` | Run Playwright browser tests |
